FAQ

Questions, answered

Which AI model does it use?

By default an open GPT-OSS model served through Groq. You can change the model name in the .env file.

Can I trust the facts in a report?

The agents are told not to invent facts or references, but AI can still make mistakes. Always verify important claims against trusted sources.

Where are my reports stored?

On your own machine, in the reports folder next to the app. Nothing is uploaded anywhere except the prompts sent to the model provider.

Do I need my own API key?

Yes. Add your Groq API key to the .env file before starting the server.
